## `03` — Selected work

### 01 / [miniOPT — Mini Compiler & Code Optimizer](https://github.com/DestinyDriver/miniOPT)
`C++17 • Compiler Design • AST • Three-Address Code • Data-Flow Analysis • CMake`

A modular optimizing compiler for an imperative C-like language, built with a handcrafted lexer, recursive-descent parser, Abstract Syntax Tree (AST), and Three-Address Code (TAC) intermediate representation.

- Implements fixed-point optimization passes including constant folding, constant propagation, algebraic simplification, common subexpression elimination, dead code elimination, and branch simplification.
- Generates pseudo-assembly for an abstract register machine and includes command-line options for inspecting compiler stages and running benchmarks.

[Repository ↗](https://github.com/DestinyDriver/miniOPT)

### 04 / [CalC — Cross-Tab Loan EMI Calculator](https://github.com/DestinyDriver/CalC)
